## Task 1 — Veri üreticisi ve normal hesap

**Risk:** veri + matematik → görev incelemesi var.

**Dosyalar:** `scripts/make_normal_data.py`, `src/concepts/normal-dagilim/data/normal_data.json`
(yalnız betikle), `src/concepts/normal-dagilim/data.ts`, `src/core/stats.ts`,
`tests/unit/core/stats.test.ts` (ek), `tests/unit/normal-dagilim/data.test.ts`.

- **Üretici:** spec "Veri" bölümündeki iki örneklem, tohum araması, koşullar ve fixture; `--check`
  kayma denetimi; docstring'de kurallar (`make_eda_data.py` kalıbı). JSON şekli:
  `{ series: { sinav: Series, cagri: Series }, norm: { bands: [k, area][], points: { x, mu, sigma, pdf, cdf }[] }, sinavFixed: { a: 60, b: 80, area, count, x: 85, z, phi } }`,
  `Series = { id, label, unit, values: number[], domain: [lo, hi], binWidth, edges: number[], counts: number[], mean, std, median, skew, band: { k, lo, hi, count }[], scaled: { mean, std0, skew } , seed }`.
  `std` ddof 1, `scaled.std0` ddof 0 (StandardScaler sonrası, ≈ 1). Yüksek hassasiyet (repr) yazılır.
- **TS hesap (`core/stats.ts`):** `std(xs, ddof = 1): number`, `normPdf(x, mu, sigma): number`,
  `normCdf(x, mu, sigma): number` (erf: W. J. Cody rasyonel yaklaşımı ya da eşdeğer, mutlak hata
  ≤ 1e-7; |z| > 8'de 0/1). Mevcut fonksiyonlar değişmez.
- **`data.ts`:** tipli `SERIES: Record<Seri, Series>`, `NORM`, `SINAV_FIXED` ihracı; `type Seri = 'sinav' | 'cagri'`.
- **Testler:** `stats.test.ts` → `normPdf matches scipy at every fixture point`,
  `normCdf matches scipy at every fixture point`, `normCdf is symmetric and hits 0.5 at the mean`,
  `std uses ddof 1 by default`; `data.test.ts` → `browser stats match the pandas fixture for both series`,
  `fixed-edge histogram counts match numpy`, `band counts match the fixture`,
  `fixture std and scaler std differ by ddof`, `sinav band fractions follow the 68-95-99.7 rule`,
  `cagri breaks the rule at one sigma`.

## Task 2 — İskelet, ortak yoğunluk katmanı, senaryo ve görünüm

**Risk:** matematik + senaryo → görev incelemesi var.

**Dosyalar:** iskelet (`npm run yeni-kavram`): `normal-dagilim/index.html`, `vite.config.ts`,
`src/concepts/normal-dagilim/{main.ts, scenario.ts, normal-dagilim.css}`; ayrıca
`src/core/plot/density.ts`, `src/concepts/normal-dagilim/view.ts`,
`tests/unit/core/density.test.ts`, `tests/unit/normal-dagilim/{scenario,view}.test.ts`.

- **`density.ts`:** `curvePath(f, x0, x1, n, sx, sy): string` (n ≥ 2 örnek, `M…L…`),
  `areaPath(f, a, b, n, sx, sy, baseY): string` (a > b ise yer değiştirir; taban çizgisinden
  kapalı alt yol, `Z` ile biter; a = b → boş string). `r1` yuvarlaması.
- **Senaryo:** 8 adım, kimlikler `histogram, egri, mu-sigma, alan, kural, z-skor, carpik, olcekleme`;
  `NormalParams = { seri; mu; sigma; a; b; x; k }`, varsayılanlar: `seri 'sinav'`, `mu`/`sigma`
  sinav'ın ortalama/std'si, `a 60`, `b 80`, `x 85`, `k 1`. Adımların `params`'ı spec'teki seri
  zorlamaları (adım 3, 4, 6 sinav; adım 7, 8 cagri). Adım→kontrol listeleri (`SERIES_STEPS`,
  `MU_SIGMA_STEPS`, `AB_STEPS`, `K_STEPS`, `X_STEPS`) `stepIndex` ile türetilir. Kısayollar
  (`dagilimShortcuts` kalıbı): S seri, K bant 1/2/3. Kontrol değiştiren adımlara `labText`.
- **`view.ts`:** `deriveNormalView(index, p): NormalView` saf; alanlar: `stepId, seri, values,
  bins ({lo, hi, count, density})[], mean, median, std, skew, curve: { mu, sigma } | null,
  ghosts: { sigma }[]`, `area: { a, b, p, count } | null`, `bands: { k, lo, hi, theory, sample }[]`,
  `zAxis: boolean`, `marker: { x, z, phi } | null`, `scaled: boolean`, `links: { href, label }[]`,
  `strip: string`, `note: string`. Adım 8'de `values` z'ye çevrilmiş değerlerdir (`zscores`),
  kenarlar da (lo − mean)/std0 ile. Biçim: spec "Ortak öğretim dili" ondalıkları, `core/plot/format`.
- **Testler:** `density.test.ts` → `curvePath has n samples`, `areaPath stays between a and b`,
  `areaPath swaps reversed bounds`, `areaPath is empty for a equal b`; `scenario.test.ts` →
  `step ids follow the spec`, `step texts read their numbers from the data`,
  `every control-changing step has a lab text` (`lab-text.ts`); `view.test.ts` →
  `density bars integrate to 1`, `step 2 curve uses the sample mean and std`,
  `step 4 area matches the scipy fixture`, `step 5 bands carry theory and sample shares`,
  `step 6 z of 85 matches the fixture`, `step 7 one-sigma share is far from 68`,
  `step 8 strip reads the scaler mean 0 and std 1`, `reversed a and b give the same area`,
  `no strip contains NaN or Infinity` (bütün adımlar × uç Lab değerleri).
