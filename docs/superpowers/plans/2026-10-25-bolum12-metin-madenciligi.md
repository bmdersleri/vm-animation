- `score.ts`: `score(model: Model, text: string)` → `{ tokens, terms: { term, weight, coef, contribution }[], oov: string[], z, p }`; `sigmoid`.
- Testler: `tokenize.test.ts` → `tokenize matches python on the twenty fixture comments`, `turkish capital i becomes dotted i`, `stop words go to dropped in order`; `vectorize.test.ts` → `tfidf matches sklearn on book examples and corpus` (1e-12), `vocabulary follows code point order`, `bigrams join with one space`, `zero vector gives cosine zero and intercept-only probability`, `transform drops and counts out-of-vocabulary terms`; `score.test.ts` → `score matches sklearn probabilities for all eight models` (1e-9), `contributions sum to z minus intercept`, `drift comments match the fixture oov counts`; `data.test.ts` → `book numbers come from data` (0,43 / 0,56; 0,14; 0,50; 0,542), `corpus split is stratified 75/25`, `keeping degil with bigrams beats dropping it on negations`, `drift oov rate is above the test rate`.
