## Task 1 — Veri üreticisi ve ortak hesap (`src/concepts/birliktelik/`)

**Risk:** veri + matematik → görev incelemesi var.

**Dosyalar:** `scripts/make_birliktelik_data.py`, `scripts/requirements.txt` (+`mlxtend`), `src/concepts/birliktelik/data/sepet.json` (yalnız betikle), `src/concepts/birliktelik/data.ts`, `src/concepts/birliktelik/metrics.ts`, `src/concepts/birliktelik/apriori.ts`, `src/concepts/birliktelik/fptree.ts`, `src/concepts/birliktelik/rules.ts`, `src/concepts/birliktelik/format.ts` (ürün adları/kısaltmalar, küme yazımı), `tests/unit/birliktelik/*.test.ts`.

- **Üretici:** spec "Ortak veri ve hesap" bölümündeki JSON'u yazar; `--check` kayma denetimi (diğer `make_*_data.py` kalıbı, docstring'de kurallar). Kitabın sayılarını doğrular, tutmazsa exit 1: ürün sayıları {ekmek 11, sut 12, yumurta 10, tereyagi 7, peynir 5, recel 3}; min_support 0,5 / 0,3 / 0,2 / 0,15 → 4 / 7 / 12 / 16 küme; her eşikte apriori = fpgrowth; 0,2 / 0,5 → 13 kural, bunların 9'u lift > 1,1; ekmek→sut güven 0,636364, lift 0,954545. Ürün kimlikleri kitaptaki ASCII adlardır; ekran adları JSON'da (`Ekmek, Süt, Yumurta, Tereyağı, Peynir, Reçel`) ve kısaltmalar (`E, S, Y, T, P, R`).
- **Arayüzler (TS):**
  - `type Item = string; type Basket = readonly Item[]; type Itemset = readonly Item[]` (her zaman ürün sırasına göre sıralı).
  - `count(tx, set)`, `support(tx, set)`, `confidence(tx, x, y): number | null`, `lift(tx, x, y): number | null`.
  - `aprioriTrace(tx, minCount): { levels: { k: number; candidates: { set: Itemset; status: 'frequent' | 'infrequent' | 'pruned'; count: number | null; prunedBy: Itemset | null }[] }[]; frequent: Map<string, number>; counted: number }` — seviye 1 bütün ürünler; k ≥ 2 adayları birleştirme (ilk k−1 öğesi aynı iki sık küme) + budama; adaylar kalmayınca durur. Kafes için `latticeState(trace, set)`: `'frequent' | 'infrequent' | 'pruned' | 'unseen'` — budanan bir kümenin bütün üst kümeleri de `pruned` sayılır (spec adım 3: Reçel'in 31 üst kümesi).
  - `fpTree(tx, minCount)`: `{ order: Item[]; filtered: Itemset[] (her fiş sıralı/süzülmüş); snapshots: Node[] (0..n fiş eklendikten sonraki ağaç); header: { item; total }[] }`, `Node = { id: string; item: Item | null; count: number; children: Node[] }` (kök `item: null`). `conditionalBase(tree, item): { path: Itemset; count: number }[]`, `fpGrowth(tx, minCount): Map<string, number>`.
  - `rules(tx, minSupport, minConfidence): { x: Itemset; y: Itemset; support: number; confidence: number; lift: number }[]` (mlxtend `association_rules` ile aynı küme; sıralama: kaldıraç azalan, eşitlikte güven azalan, sonra küme yazımı).
- **Testler:** `apriori.test.ts` → `frequent itemsets match mlxtend for every min_support`, `trace at 4 baskets counts 18 candidates and finds 12 sets`, `level 3 prunes EST and ETY without counting`, `every superset of an infrequent set is pruned in the lattice`; `fptree.test.ts` → `fp-growth finds the same sets as apriori for every min_support`, `items are ordered by frequency and recel is dropped at 4 baskets`, `the last snapshot counts sum to the filtered baskets`, `peynir conditional base gives sut 4 and yumurta 4`; `rules.test.ts` → `rules at 0.2 and 0.5 match mlxtend`, `rule counts match the mlxtend grid`, `9 of 13 rules have lift above 1.1`; `metrics.test.ts` → `book numbers: ekmek 11/18, ekmek and sut 7/18, confidence 0.636 and 0.583, lift 0.955`, `undefined confidence and lift return null`.
